# Polskie tlumaczenie wlasnych komunikatow moda dostepnosci do Darkest Dungeon.
#
# Powstalo na podstawie szablonu Mod\lang\english.txt i zachowuje jego kolejnosc.
# Slownictwo pochodzi z wlasnych polskich tabel gry (str_glossary_term_*, town_name_*,
# upgrade_tree_tooltip_*, str_ui_*): nawyk = quirk, blyskotka = trinket, pamiatka = heirloom,
# sklad = roster, obiekt = curio, Wrota Smierci = Death's Door, udreka = affliction,
# cnota = virtue, biegłosc = skill, Poziom Woli = Resolve level, Osada = Hamlet, Sala = Room,
# Korytarz = Hallway, Zapasy = Provision, Lupy = Loot, Zwiad = Scouting, misja = quest.
#
# "Rank" po angielsku znaczy w tym modzie trzy rozne rzeczy; polski je rozroznia tak jak gra:
#   - miejsce w szyku bitewnym  -> POZYCJA   (character_title_position_pips, buff_rule_tooltip_in_rank)
#   - stopien ulepszenia        -> POZIOM    (upgrade_tree_tooltip_..._of_rank_format: "do poziomu %d")
#   - ranga w Cyrku             -> RANGA     (str_glossary_term_2004)
#
# Liczebniki: polski odmienia rzeczownik inaczej dla 1, 2-4 i 5+, a tlumacz nie widzi wartosci
# %d. Kazda liczba zmienna jest wiec zapisana jako etykieta "Rzeczownik: %d", ktora jest
# poprawna dla kazdej liczby -- tak jak robi to sama gra (game_over_number_of_weeks_format:
# "Tygodnie: %d"). Tam gdzie liczba jest STALA (blok BFX_*), rzeczownik jest odmieniony
# normalnie.
