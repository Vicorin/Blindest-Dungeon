# Simplified Chinese translation of the Darkest Dungeon accessibility mod's own spoken strings.
# 暗黑地牢无障碍模组自有语音文本的简体中文翻译。
#
# Embedded as "schinese" (the game's internal name: schinese.loc2). Written 2026-09-17 against
# Mod\lang\english.txt, in the template's own order. Vocabulary follows the game's own
# shipped Simplified Chinese tables (str_glossary_term_*, town_name_*): 特质 = quirk,
# 饰品 = trinket, 祖产 = heirloom, 英雄名册 = roster, 压力 = stress, 奇物 = curio,
# 砺炼值 = Resolve XP, 决心等级 = Resolve level, 增益/减益 = buff/debuff, 小镇 = Hamlet,
# 扎营 = camping, 补给 = provisions, 侦察 = scouting, 濒死 = Death's Door.
# The game says 第N位 for a place in the battle line and 等级/级 for an upgrade step; this
# file keeps that split (RV_POSITION_FMT = 第%d位, BLD_BOUGHT_RANK_FMT = 第%d级). Tier = 阶.
# The game leaves "The Butcher's Circus" in English and calls the venue 赛场; so does this file.
# Format: IDENTIFIER=text, UTF-8, printf placeholders kept verbatim and in English order.
