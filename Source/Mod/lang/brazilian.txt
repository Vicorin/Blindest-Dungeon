# Brazilian Portuguese translation of the Darkest Dungeon accessibility mod's own spoken strings.
# Traducao para portugues do Brasil dos textos falados pelo proprio mod.
#
# Embedded as "brazilian" (the game's internal name: brazilian.loc2). Written 2026-09-17 against
# Mod\lang\english.txt, in the template's own order. Vocabulary follows the game's own
# Brazilian string tables (str_glossary_term_*, town_name_*, upgrade_tree_tooltip_*):
# quirk = peculiaridade, trinket = preciosidade, heirloom = heranca, roster = equipe,
# party = grupo, stress = estresse, curio = objeto, buff/debuff = bonus/penalidade,
# Hamlet = Aldeia, Death's Door = Portas da Morte, Resolve XP = EXP de determinacao.
# A place in the battle line is a "posicao"; an upgrade step is an "estagio".
# See README.txt for the format. Master list of identifiers: Mod\src\core\axstrings.inc
