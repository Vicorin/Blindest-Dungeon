# Cesky preklad vlastnich hlasek modu pristupnosti pro Darkest Dungeon.
#
# Vznikl ze sablony Mod\lang\english.txt a zachovava jeji poradi.
# Slovnik pochazi z vlastnich ceskych tabulek hry (str_glossary_term_*, town_name_*,
# upgrade_tree_tooltip_*, str_ui_*): osobnostni rys = quirk, cetka = trinket,
# rodinna cennost = heirloom, soupiska = roster, rekvizita = curio, prah smrti = Death's Door,
# sklicenost = affliction, povznesenost = virtue, posileni/postih = buff/debuff,
# uroven odhodlani = Resolve level, Vesnice = Hamlet, mistnost = room, chodba = hallway,
# zasoby = provision, korist = loot, pruzkum = scouting, vyprava = quest, kobka = dungeon.
#
# "Rank" znamena v anglictine modu tri ruzne veci; cestina je rozlisuje stejne jako hra:
#   - misto v bojove formaci -> POZICE   (character_title_position_pips, buff_rule_tooltip_in_rank)
#   - stupen vylepseni       -> UROVEN   (upgrade_tree_tooltip_..._of_rank_format: "na %d. uroven")
#   - hodnost v Cirkusu      -> HODNOST  (str_glossary_term_2004), tier = STUPEN (2005), liga (2006)
#
# Cislovky: cestina sklonuje podstatne jmeno jinak pro 1, 2-4 a 5+, a prekladatel hodnotu %d
# nevidi. Kazdy promenny pocet je proto zapsan jako stitek "Podstatne jmeno: %d", ktery je
# spravny pro kazde cislo -- stejne jako to dela sama hra ("Zbyva pouziti: %d", "Urov.: %d").
# Kde je cislo PEVNE (blok BFX_*), je podstatne jmeno sklonovano normalne.
#
# Rod: cesky minuly cas se shoduje s rodem podmetu, ktery za %s prekladatel nevidi (hrdina
# i hrdinka). Vety s %s jako podmetem jsou proto psany v pritomnem case nebo neosobne.
