# Traduzione italiana delle frasi proprie della mod di accessibilità per Darkest Dungeon.
#
# Nata dal modello Mod\lang\english.txt e ne mantiene l'ordine.
# Il lessico viene dalle tabelle italiane del gioco stesso (str_glossary_term_*, town_name_*,
# upgrade_tree_tooltip_*, str_controls_*): tratto = quirk, ornamento = trinket,
# cimelio = heirloom, ranghi = roster, reperto = curio, Punto di Morte = Death's Door,
# afflizione/virtù = affliction/virtue, PE di Risolutezza = Resolve XP, Borgo = Hamlet,
# Villaggio = Town, stanza = room, corridoio = hallway, provvista = provision, bottino = loot,
# esplorazione = scouting, missione = quest, dungeon = dungeon, gruppo = party,
# Accampamento = camping, Distretti = Districts, vessillo = banner, Lega = league.
#
# "Rank" in inglese significa tre cose diverse; l'italiano le distingue come fa il gioco:
#   - posto nella formazione di battaglia -> POSIZIONE (character_title_position_pips,
#                                            buff_rule_tooltip_in_rank)
#   - grado di miglioria                  -> LIVELLO   (upgrade_tree_tooltip_..._of_rank_format)
#   - rango nel Circo                     -> RANGO     (str_glossary_term_2004); tier = LIVELLO (2005)
# Il gioco usa "livello" sia per rank sia per tier delle migliorie: dove le due righe
# convivono (HA_HEAD_NEXT_RANK / HA_HEAD_NEXT_TIER) sono distinte a mano.
#
# Numeri: chi traduce non vede il valore di %d, quindi "1 edifici" sarebbe possibile. Ogni
# conteggio variabile di un sostantivo della mod è scritto come etichetta "Sostantivo: %d",
# corretta per ogni numero -- come fa il gioco stesso.
#
# Genere: %s può essere un eroe o un'eroina, e il participio con "essere" concorda col
# soggetto ("si è unito/unita"). Le frasi con %s come soggetto sono quindi scritte al presente,
# con "avere", o come etichetta "Etichetta: %s".
