# Korean translation of the Darkest Dungeon accessibility mod's own spoken strings.
# 다키스트 던전 접근성 모드가 직접 말하는 문구의 한국어 번역.
#
# Embedded as "koreana" (the game's internal name: koreana.loc2). Written 2026-09-17 against
# Mod\lang\english.txt, in the template's own order. Vocabulary follows the game's own
# shipped Korean tables (str_glossary_term_*, town_name_*): 기벽 = quirk, 장신구 = trinket,
# 가보 = heirloom, 명단 = roster, 스트레스 = stress, 골동품 = curio, 의지 경험치 = Resolve XP,
# 의지 레벨 = Resolve level, 강화/약화 = buff/debuff, 영지 = Hamlet, 야영 = camping,
# 보급품 = provisions, 정찰 = scouting, 횃불 = torch, 불빛 = torchlight,
# 죽음의 문턱 = Death's Door, 원정 = quest, 출정 = embark, 후퇴 = retreat, 붕괴 = affliction.
# The game says %d열 for a place in the battle line and %d급 for an upgrade step; this file
# keeps that split (RV_POSITION_FMT = %d열, BLD_BOUGHT_RANK_FMT = %d급).
# STYLE: never attach a Korean particle directly to a %s -- the substituted noun's final
# consonant decides 이/가, 을/를, 은/는, and a screen reader reads "을(를)" aloud. Phrase the
# sentence so the placeholder is followed by a space instead.
# Format: IDENTIFIER=text, UTF-8, printf placeholders kept verbatim and in English order.
