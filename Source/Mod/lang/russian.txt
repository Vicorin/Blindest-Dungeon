# Russian translation of the Darkest Dungeon accessibility mod's own spoken strings.
# Русский перевод собственных реплик мода доступности для Darkest Dungeon.
#
# Embedded as "russian" (the game's internal name: russian.loc2). Written 2026-09-17 against
# Mod\lang\english.txt, in the template's own order. Vocabulary follows the game's own
# shipped Russian tables (str_glossary_term_*, town_name_*, dungeon_name_*, str_ui_*):
# черта = quirk, украшение = trinket, фамильные ценности = heirlooms, список героев = roster,
# диковинка = curio, стресс = stress, очки решимости = Resolve XP, уровень решимости =
# Resolve level, усиление/ослабление = buff/debuff, город = Hamlet, лагерь = camping,
# разведка = scouting, факел = torch, факельный свет = torchlight, при смерти = Death's Door,
# психоз = affliction, душевный подъём = virtue, задание = quest, добыча = loot,
# комната = room, коридор = hallway, кампания = Campaign, предместье = Districts,
# припасы = provisions, инвентарь = the party bag, ячейка = slot, арена = The Ring.
# The game says ПОЗИЦИЯ for a place in the battle line (character_title_position_pips =
# "Лучшая позиция") and РАНГ for an upgrade step (upgrade_tree_tooltip_..._of_rank_format =
# "до ранга %d"); this file keeps that split.
# STYLE: short impersonal sentences, no second-person imperatives where a noun phrase will do,
# so a line stays short when spoken. Counts are written "Noun-genitive-plural: %d", which is
# grammatical for every number and avoids the 1/2/5 agreement trap.
# Format: IDENTIFIER=text, UTF-8, printf placeholders kept verbatim and in English order.
