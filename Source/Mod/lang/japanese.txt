# Japanese translation of the Darkest Dungeon accessibility mod's own spoken strings.
# ダーケストダンジョン アクセシビリティモッドが自ら読み上げる文章の日本語訳。
#
# Embedded as "japanese" (the game's internal name: japanese.loc2). Written 2026-09-17 against
# Mod\lang\english.txt, in the template's own order. Vocabulary follows the game's own
# shipped Japanese tables (str_glossary_term_*, town_name_*, dungeon_name_*): 奇癖 = quirk,
# トリンケット = trinket, 家宝 = heirloom, メンバーリスト = roster, キュリオ = curio,
# ストレス = stress, リゾルブXP = Resolve XP, リゾルブレベル = Resolve level,
# 強化/弱体化 = buff/debuff, 村 = Hamlet, キャンプ = camping, 偵察 = scouting,
# たいまつ = torch, 光量 = torchlight, デスドア = Death's Door, 精神崩壊 = affliction,
# 徳 = virtue, クエスト = quest, 出発 = embark, 戦利品 = loot, 広間 = room, 廊下 = hallway,
# アイテムリスト = the party inventory, 区画 = Districts, 探索 = Campaign.
# The game says ポジション for a place in the battle line and ランク for an upgrade step;
# this file keeps that split (RV_POSITION_FMT = ポジション%d, BLD_BOUGHT_RANK_FMT = ランク%d).
# STYLE: polite short forms (ます / ません) for sentences, bare noun phrases for labels, so a
# line stays short when spoken. The game leaves The Butcher's Circus and its screens in English
# in the Japanese build, so the proper nouns here stay English too.
# Format: IDENTIFIER=text, UTF-8, printf placeholders kept verbatim and in English order.
